# sensor-test（かたむき そくてい）

うごく あそび（ugoku-asobi）を作る前に、端末の傾きの角度を測るための支援者用のページです。案内に沿って遊ぶと自動で測り、最後に結果が出ます。

## 流れ（3分くらい）
1. だれが持つかを選ぶ（子ども／大人／いっしょに）。名前は記録しません。
2. センサーを許可する。
3. ふだんの持ち方で2秒じっと → その持ち方を「水平（0°）」にします。
4. じっと5秒：手ぶれの大きさを測ります（ボールのおわん）。
5. ておしぐるま（2回）：前に傾けると子どもが進み、はたまで行きます。自然に傾けた角度を測ります。前の向きは自動で決まります。
6. はたに着いたら、水平にもどす：もどるまでの時間と、もどしたあとのゆれを測ります。
7. ゆりかご（15秒）：左右に傾けた角度を測ります。
8. 結果：数字と、手助け（大きい・ふつう・小さい）の角度のめやすが出ます。「コピー」か「テキストで保存」で残します。

## 注意
- データは保存しません。ページを閉じると消えます。
- 画面の左上に、いまの角度が小さく出ます（支援者用）。
- めやすは、この端末・この持ち方での目安です。最後は、実際の子どもの様子で決めてください。
