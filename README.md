# sensor-test

うごく あそび（ugoku-asobi）の前に、端末の傾きを測るための支援者用テストページです。子どもには見せません。

## 使い方
1. 公開された URL を iPhone か小さめの iPad で開きます。
2. 「センサーを許可する」を押して、許可します。
3. 座って、普段の持ち方で持ち、「水平にする」を押します。
4. 次の順で測ります。
   - じっと5秒：手ぶれの幅を見ます。
   - 前へ傾けて、少し／ふつう／大きく の順に「記録」を押します。
   - 左右にも傾けて、同じように記録します（ゆりかご用）。
   - 水平に戻して「戻ったら3秒はかる」を押し、戻したあとのずれを見ます。
5. 「結果をコピー」で、数字を貼り付けて控えます。

## 注意
- データは保存しません。ページを閉じると消えます。
- 数字は、水平を0とした角度です。
- 端末を回転させると、前後と左右の向きが変わるので、測り直してください。
- 子どもの名前・記録・顔・声は扱いません。

## 公開
- Cloudflare Pages（Workers）で `public/` を公開します。`wrangler.jsonc` の assets directory は `./public` です。
